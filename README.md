# gitZ-CORE

**Système Central d'Intelligence Artificielle**

Repository principal regroupant l'architecture, les pipelines et les prototypes de mes projets IA.

### Vision
gitZ-CORE est le noyau central qui orchestre mes travaux en IA appliquée aux domaines critiques :
- Santé numérique (Standards FHIR & SNOMED CT)
- Cybersécurité intelligente (NetSecurePro IA)
- MLOps & Data Engineering sur Snowflake

### Projets intégrés

#### 1. ORBITRON.IA – Pipeline Santé Snowflake
- Pipeline MLOps complet sur Snowflake Data Cloud
- Gestion sécurisée des données FHIR (chiffrement, UDFs, pseudonymisation)
- Feature Engineering avec Snowpark
- Observabilité ML et détection de drift

#### 2. NetSecurePro IA – Cybersécurité
- Détection d’anomalies en temps réel sur logs réseau
- Détection "Impossible Travel" avec géolocalisation IP
- Filtrage intelligent des VPN et Threat Intelligence
- Architecture scalable avec Snowpark

#### 3. Z-AICLAUDE.IA & ZCLAUDE.CODE
- Interfaces et agents IA (Gemini + Claude)
- Outils internes de génération de code et d’analyse

### Technologies Maîtresses
- **Snowflake** — Snowpark, UDFs, Data Cloud
- **Standards Santé** — FHIR, SNOMED CT
- **Cybersécurité** — Logs analysis, Géolocalisation, Impossible Travel
- **IA & MLOps** — Gemini API, Observabilité, Feature Store
- **Déploiement** — Google Cloud Run, Vite, TypeScript

### Structure du Repository (en cours)
- `/projects/` → ORBITRON.IA, NetSecurePro, etc.
- `/src/` → Code commun et agents
- `/docs/` → Architecture, diagrammes, présentations
- `/presentations/` → Parkinson IA, etc.
